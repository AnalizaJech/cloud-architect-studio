# Security policy

## Supported versions

The current `main` release receives security fixes.

## Reporting

Please report vulnerabilities privately through GitHub's **Report a vulnerability** feature when enabled, or contact the repository maintainer through a private channel listed in the repository profile. Do not publish exploit details before a fix is available.

Include the affected version, reproduction steps, expected impact and a minimal proof of concept. Avoid sharing real user diagrams or credentials.

Diagram data remains in the browser. The app has no server-side account or telemetry service. Imported JSON is validated before rendering.
